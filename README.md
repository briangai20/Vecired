# VeciRed

App para encontrar productos en los comercios del barrio, reservarlos y retirarlos en el local (Click & Collect). Arranca en Ingeniero Maschwitz (partido de Escobar).

- `web/`: la app (Next.js + Supabase). Para correrla: `cd web`, `npm install`, copiar `.env.example` a `.env.local` y `npm run dev`.
- `supabase/`: esquema de la base, pruebas y datos de prueba.
- `index.html` y `VECIRED OFFLINE/`: prototipos anteriores.
